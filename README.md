# UUM Handball Team — merch site

Vite + React site for UUM Handball Team jerseys and training kits, deployed on Netlify.

- Products, prices, sizes and the order form link: `src/data.js`
- Jersey images: `images/`
- Firebase (optional, for analytics): copy `.env.example` to `.env` and fill in your Firebase web config, or add the same variables in Netlify → Site configuration → Environment variables.

```bash
npm install
npm run dev     # local preview
npm run build   # production build in dist/
```
